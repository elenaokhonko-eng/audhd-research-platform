# 0001 Region: asia-southeast1 (Singapore)

Date: 2026-11-15 · Status: accepted

Context: participant and member data will be collected from Stage 1; the owner is in Singapore; PDPA applies; Firestore and BigQuery locations cannot be changed after creation.
Decision: every regional resource uses asia-southeast1.
Consequences: lowest latency for the owner; domain mappings are available there (preview). Moving later means migrating data, so this is decided before Stage 1.
